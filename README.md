# Portafolio de Ciencia de Datos e Inteligencia Artificial

Bienvenido a mi portafolio de proyectos. Aquí reúno trabajos de análisis de datos, aprendizaje automático, inteligencia artificial y desarrollo de soluciones analíticas. Cada proyecto aborda un problema distinto y documenta el enfoque utilizado y sus resultados.

## Proyectos destacados

### [Agente de Optimización y Evaluación de Portafolios de Inversión](https://github.com/Cheski1610/Agente_Evaluador_Portafolios)
Herramienta para analizar y optimizar portafolios financieros con el modelo media-varianza de Markowitz. Descarga precios históricos, calcula asignaciones y métricas de riesgo, y ofrece una interfaz de línea de comandos, una aplicación web y un agente conversacional.

### [Intelligent Risk Monitoring Lab](https://github.com/Cheski1610/intelligent-risk-monitoring)
Laboratorio educativo que utiliza transacciones sintéticas de PaySim para detectar anomalías, observar indicadores de riesgo a lo largo del tiempo y preparar investigaciones con evidencia documental. Sus alertas sirven para priorizar revisiones; no confirman fraude.

### [Predictor de Variables Económicas y Análisis de Noticias con IA](https://github.com/Cheski1610/proyecto_tfm)
Asistente web para analizar indicadores macroeconómicos de Costa Rica. Consulta datos del Banco Central, genera pronósticos con Prophet y resume noticias recientes para dar contexto a los resultados.

### [Aplicación RAG con Qwen3](https://github.com/Cheski1610/Rag_Qwen3)
Permite cargar documentos PDF, recuperar fragmentos relevantes y generar respuestas con un flujo RAG. Incluye una aplicación web, un script de línea de comandos y un notebook; utiliza embeddings y una base vectorial ChromaDB, con distintos proveedores de generación configurables.

## Todos los proyectos

### Análisis exploratorio de datos

- [Análisis Exploratorio de Datos Automatizado](https://github.com/Cheski1610/EDAutomated): aplicación web para generar automáticamente un análisis exploratorio de datos, con recursos para ejecutarla en contenedores y desplegarla en Azure.
- [Informe Mundial de Felicidad (Python)](https://github.com/Cheski1610/Portafolio_Proyectos/tree/main/EDA%20-%20Informe%20Mundial%20de%20Felicidad%20(Python)): explora las puntuaciones de felicidad de distintos países y su relación con indicadores como apoyo social, economía, esperanza de vida, libertad y percepción de corrupción.
- [Airbnb Milan 2019 (R)](https://github.com/Cheski1610/Portafolio_Proyectos/tree/main/EDA%20-%20Airbnb%20Milan%202019%20(R)): analiza alojamientos completos en Milán y compara precios, reseñas y calificaciones según características del anfitrión, como su verificación y condición de superhost.

### Modelado y evaluación de sistemas predictivos

- [Evaluación de las Predicciones del Sistema COMPAS](https://github.com/Cheski1610/Portafolio_Proyectos/tree/main/Evaluaci%C3%B3n%20Predicciones%20Sistema%20COMPAS): examina las puntuaciones de riesgo de reincidencia de COMPAS y las contrasta con registros históricos de reincidencia.
- [Regresión Lineal Regularizada para la Predicción de Salarios (R)](https://github.com/Cheski1610/Portafolio_Proyectos/tree/main/Regresi%C3%B3n%20Lineal%20Predicciones%20Salarios): explora datos de salarios de profesores universitarios y desarrolla un modelo lineal regularizado usando variables como rango académico, disciplina y experiencia.
- [Clasificación de la Intención de Compra en una Tienda Online](https://github.com/Cheski1610/Portafolio_Proyectos/tree/main/Modelado%20Intenci%C3%B3n%20Compra%20Online): prepara datos de sesiones de navegación y compara modelos de clasificación para predecir si una visita terminará en una compra, evaluándolos con validación cruzada y ROC.
- [Estimación de Precios de Vehículos Usados — metodología CRISP-DM](https://github.com/Cheski1610/Portafolio_Proyectos/tree/main/Estimaci%C3%B3n%20Precio%20Veh%C3%ADculos%20Usados%20-%20CRISP-DM): plantea un caso de negocio para estimar precios de vehículos usados y desarrolla el análisis siguiendo las fases de CRISP-DM.

### Aplicaciones de datos y análisis geoespacial

- [Mapa Cantonal de Costa Rica](https://github.com/Cheski1610/mapacantonalcr): aplicación de visualización geográfica de indicadores económicos y territoriales de los cantones de Costa Rica.
- [Aplicación para la Predicción de Cargos por Seguros](https://github.com/Cheski1610/ExamplePycaret): aplicación web local creada con Streamlit y PyCaret para predecir cargos de seguros. Utiliza un modelo Gradient Boosting, seleccionado por sus métricas frente a la regresión lineal evaluada como alternativa.

### Optimización

- [Optimización de Campañas de Marketing Online con Aprendizaje por Refuerzo](https://github.com/Cheski1610/Portafolio_Proyectos/tree/main/Optimizaci%C3%B3n%20Campa%C3%B1a%20de%20Marketing%20Online): aplica un algoritmo de bandido multibrazo para elegir entre distintas imágenes de un anuncio y aumentar los clics, balanceando exploración y explotación.
